# 红楼梦（一百零八回足本）开源共享版

**撰次：西域吃沙的峰兄**

## 一、这是什么

这是一部以《吴氏石头记》（俗称"鬼本"，癸酉本系统，一百零八回）剧情框架为骨的《红楼梦》足本整理工程成品：

- **第一回至第八十回**：以脂评本文字为基准骨干（雪芹原笔，仅校订电子残损），鬼本回目全卷一贯，鬼本独有的承重内容（第10回"秦可卿淫上天香楼"、第13回天香楼事发、第64回多浑虫段、第67回宝玉惋故友、第80回迎春回门与香菱病笃、第17/18回分回切齐等）依脂本语感织入；
- **第八十一回至第一百零八回**：鬼本剧情框架下的精修定稿——字数不设限、以文气为度，人物声口据前八十回档案逐一校准，判词曲文与关键脂批暗合于行文；
- **前后缝合**：80→81接口严丝合缝，23组伏线锚点逐项核验通过，四季物候（82-108回为冬章）全卷一体。

## 二、AI 工作量声明

本项由个人（西域吃沙的峰兄）发起并主持思路：版本对勘之取舍、人物声口之拟定、润色精修之规范、前后缝合之总检，皆出个人思路与决断。对勘、汇校、润色、精修、排版的文字执行工作由 **GLM-5.3-Flash 大语言模型**（智谱）承担——全程动用子代理任务88项，**累计消耗 tokens 64,596,891（约6,460万，子代理精确口径）**，加主控会话估算后全项目约7,500万–9,500万tokens。分阶段账目与口径说明见《文档集/03_项目用量统计.md》。谨志于此，以见人机相得之谊，并致敬 AI 之劳。

## 四、底本与口径

- **鬼本底本**：网络流传《吴氏石头记》扫描PDF（892页，有文字层），经页眉切分为108回、剥离杂讯而成；其真伪学界尚无定论，本书不作判断，仅以之为剧情框架。
- **脂本底本**：网络通行脂评本汇校电子本（gitbook源），批语4089条另辑全集。
- **程高本**：仅作语言风格参照与个别残损处对校，不采其改笔入正文。
